SafeMigrate checks a foreign job offer before a worker pays. 6M+ people leave JAPAC each year; recruitment fraud and scam-compound trafficking follow them. A worker forwards the offer as a photo, WhatsApp screenshot, voice note or text (web or Telegram). A Gemini agent on Cloud Run reads it in any language, calls 3 tools (government agency registry, fraud-case list digitised from DoFE PDFs by Gemini, cross-border recruiter network) and returns structured facts. A deterministic rules engine then marks every claim red, amber or green with its source, never saying "safe". Firestore holds 7,072 real agency records from Nepal (DoFE) and Pakistan (BEOE), the fraud list, anonymised cases and HMAC recruiter fingerprints, so a number reported in Nepal warns a worker in Pakistan. Gemini TTS reads the verdict aloud in Nepali. Firebase Hosting serves the app; Firestore rules block all browser access. Built in Kathmandu by a team who received this exact scam.
