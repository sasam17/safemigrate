SafeMigrate checks a foreign job offer before a worker pays. 6M+ people leave JAPAC each year; recruitment fraud and scam-compound trafficking follow them. A worker forwards the offer as a photo, WhatsApp screenshot, voice note or text, in 7 languages (Nepali, Urdu, Hindi, Bengali, Tagalog, Indonesian, English). A Gemini agent reads it multimodally, calls 3 tools by function calling (government agency registry, fraud list, cross-border recruiter network) and returns schema-structured facts. A unit-tested rules engine then marks every claim red, amber or green with its source, never saying "safe". Real data: 7,072 agency records from Nepal (DoFE) and Pakistan (BEOE), with official numbers to catch impersonation. HMAC recruiter fingerprints let a number reported in Nepal warn a worker in Pakistan. Gemini TTS speaks the verdict. Web app on Firebase Hosting; Node API built for Cloud Run with Firestore storage (Dockerfile, rules and seed included). Built in Kathmandu by a team who got this exact scam.
